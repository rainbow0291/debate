# News Issue Debate Briefing

한국경제 뉴스에서 논쟁적인 쟁점을 뽑아, 찬성/반대 논거를 서로 다른 출처로
교차 검증해 중립적으로 정리해주는 Cowork/Claude 플러그인입니다. 투자 리서치
플러그인이 아니라 "이 이슈에서 실제로 양쪽이 뭐라고 주장하는지"를 정리하는
용도예요.

## 이 플러그인이 하는 일

"이 뉴스 쟁점 정리해줘", "오늘 뉴스 중 찬반 논쟁 있는 이슈 뽑아줘" 같은
요청을 하면:

1. 논쟁거리가 될 만한 이슈(정책 변경, 규제안, 판결, 노사 갈등 등)를
   골라내고, 사실 보도성 기사면 억지로 찬반 구도를 만들지 않고 그냥
   요약해줍니다.
2. 이슈를 중립적인 한 줄 질문으로 정리합니다.
3. **찬성 측 에이전트**와 **반대 측 에이전트**를 서로 결과를 못 보게 독립적으로
   실행해, 각자 실제로 존재하는 출처(기사, 공식 발표, 통계, 성명 등)에 근거한
   논거를 찾게 합니다. 반대 측은 한국경제 밖의 다른 매체·1차 자료도 적극
   찾도록 지시되어 있어요 
4. 두 결과를 합쳐 배경·찬성 논거·반대 논거·중립 고지문이 있는 브리핑으로
   정리합니다. 못 찾은 쪽은 지어내지 않고 "확인 불가"로 표시합니다.
5. 기본은 채팅에 바로 보여주고, 원하면 기존에 설정해둔 이메일(SMTP)이나
   카카오톡(PlayMCP)으로도 보낼 수 있습니다.

## 구성 요소 (마켓플레이스 데모용으로 다양하게 구성)

- **스킬** `issue-debate`: 전체 절차를 담당
- **에이전트** `pro-advocate` / `con-advocate`: 서로 안 보이는 상태로 각자
  최선의 논거를 찾는 대립 구도 서브에이전트
- **훅** `PostToolUse` (`scripts/check_balance.py`): 브리핑 초안 파일
  (`issue-brief*.md`)을 저장할 때, 찬성/반대 양쪽에 출처가 달려 있는지
  자동으로 검사해 부실하면 막고 보완을 요구하는 안전장치
- **MCP**: 기본 번들에는 포함하지 않았습니다 (아래 "선택적 MCP 연동" 참고).

## 알려두면 좋은 점

- 이 플러그인은 어떤 입장이 "옳다"고 판단하지 않습니다. 항상 "찬성 측은
  ~라고 주장한다" 식으로 출처를 밝혀 전달하고, 결론을 내려달라는 요청은
  정중히 거절하도록 되어 있어요.
- 훅의 균형 검사는 휴리스틱(출처 링크/확인불가 문구 유무)이라 완벽하지
  않습니다 — 실제 논거 품질은 여전히 스킬/에이전트가 잘 조사했는지에
  달려 있어요.
- 이메일/카카오톡 발송 옵션은 이 계정에 이미 설정된 SMTP `.env`나 PlayMCP
  커넥터를 재사용합니다. 별도의 자격증명을 새로 요구하지 않아요.

## 선택적 MCP 연동: 국회 의안정보 (선택 설치)

법안·규제안이 걸린 이슈일 때, 실제 의안 상태(제안일·소관위·처리 단계 등)를
배경 사실로 곁들이고 싶다면 오픈소스 `assembly-api-mcp`를 직접 설치해서
연결할 수 있어요. 이 플러그인에 기본으로 포함되어 있지는 않습니다 —
본인 명의의 API 키가 필요한 외부 프로젝트라 저희가 대신 발급하거나 설치할
수 없기 때문이에요.

1. https://open.assembly.go.kr 에서 회원가입 후 API 키를 발급받으세요.
2. 터미널에서 `npx assembly-api-mcp setup`을 실행하면 키 입력부터 Claude
   설정까지 대화형으로 안내해줍니다. (참고: [assembly-api-mcp
   저장소](https://github.com/hollobit/assembly-api-mcp))
3. 연결되면 이 플러그인의 스킬이 자동으로 그 도구(`assembly_bill` 등)를
   감지해서, 법안 관련 이슈에 실제 의안 상태를 사실 배경으로 추가합니다.
   연결 안 돼 있어도 나머지 기능은 그대로 동작해요 — 필수 아님.

**통계청(KOSIS) 연동은 이번 버전에서는 넣지 않았어요.** 검토는 해봤는데
(제3자가 운영하는 무료 원격 MCP 서버 `korea-stats-mcp` vs. 공식 KOSIS
Open API를 본인 키로 직접 호출하는 방식), 둘 다 추가 설정/신뢰 판단이
필요해서 일단 제외했습니다. 나중에 필요하시면 다시 논의해서 추가할 수
있어요.
